# Reading Lamp — 英語多読アプリ

Extensive Reading (ER, 多読) の研究知見にもとづいて設計した PWA です。スマホのホーム画面に追加してネイティブアプリのように使えます。

## 設計の土台となっている多読の原則

このアプリの仕様は、以下の原則から逆算して作られています。機能を足したり変えたりするときは、この表と照らして判断してください。

| 原則 | アプリでの実装 |
|---|---|
| テキストは「やさしい」こと（既知語95〜98%、未知語は100語あたり1〜2語） | レベル1〜10のグレーデッド・リーダー準拠の語彙帯。生成プロンプトの最優先ルールとして明記 |
| 「少し易しすぎる」レベルから始め、退屈になってから上げる | 読後に3択で読みごこちを申告 → レベルを自動調整。難のときは即下げ、易のときだけ上げる |
| 量が学習効果の中核（年間100万語が目標） | ホーム画面の主役は累計語数カウンタ。1万→100万語の節目バーを表示 |
| 読書速度・流暢さの向上が主要な成果指標 | 読書時間を自動計測し、語/分 (wpm) を直近5回平均で表示 |
| 辞書使用は最小限。分からない語は飛ばす | 本文画面に辞書機能を一切置かない。ホームで毎回リマインド |
| 読書そのものが報酬。読後テストは行わない | 振り返り・語彙リスト・理解度クイズの機能は持たない |
| 読み手が読みたいものを自分で選ぶ | テーマ選択（8カテゴリ＋自由入力＋おまかせ） |
| 退屈な本はやめてよい（脱落の自由） | 本文画面に「これはやめて、別の文章にする」。語数は加算せず、記録には残る |
| 毎日同じ時間に少量でも継続 | 連続日数と1日の目標語数（既定1,500語）を表示 |

## レベルの目安

| Lv | 語彙帯 | 目安 |
|---|---|---|
| 1 | 300語 | ごく易しい。短く単純な文 |
| 2 | 600語 | 日常的な話題 |
| 3 | 800語 | 単純な物語が読める |
| 4 | 1,000語 | 時制が自在に |
| 5 | 1,400語 | 描写や説明が増える（初期値） |
| 6 | 1,800語 | 抽象的な話題も少し |
| 7 | 2,500語 | 複文や比喩が自然に |
| 8 | 3,000語 | 論説的な文章も |
| 9 | 4,000語 | 原書に近い語彙 |
| 10 | 無制限 | 簡略化なし。一般書・報道と同水準 |

初期値はレベル5です。TOEIC 750 / B2 相当の力があっても、多読では実力より低いところから始めるのが正解です。「退屈なほど楽」と感じるまで上げないでください。上げるのを急ぐと、多読ではなく精読になってしまいます。

## オフラインの文章バンク（APIキー不要）

設定画面の「オフラインの文章バンクを使う」をオンにすると、Anthropic APIを一切呼ばずに、あらかじめ用意した文章から出題します。通信費・API利用料がかからず、完全オフラインでも使えます。

- 現在収録：**694篇**（レベル1〜10 × 全7テーマ：Fantasy/stories・Famous books・Nature and animals・World affairs・Everyday life・History・Science）
- 各テーマ・各レベルに複数篇を収録済み。今後も随時追加予定
- 選んだテーマとレベルの組み合わせの中で、一度読んだ文章は他のストックがなくなるまで再表示されません。読み尽くすと記録をリセットして次の周からまた出題します（直前に読んだ1篇だけは連続を避けます）
- レベル調整（読後の3択フィードバック）は文章バンクモードでも動作します

文章を追加する場合は、`stories.json`に同じ形式（`id`・`level`・`topic`・`title`・`text`）でオブジェクトを追加するだけで反映されます。

## 必要なもの

- Anthropic の API キー（<https://console.anthropic.com/settings/keys>。従量課金）
- HTTPS ホスティング先（PWAとしてインストールするには `http://localhost` か `https://` が必須）

## 公開方法（おすすめ：GitHub Pages、無料）

1. GitHub に新しいリポジトリを作り、このフォルダの中身一式をアップロード
2. Settings → Pages で公開元を「main ブランチ / root」に設定
3. 発行された `https://アカウント名.github.io/リポジトリ名/` にスマホでアクセス
4. iPhone Safari なら共有 →「ホーム画面に追加」、Android Chrome なら右上メニュー →「アプリをインストール」

Netlify・Vercel・Cloudflare Pages へのドラッグ＆ドロップでも構いません。

## 使い方

1. 右上の歯車から API キーを設定
2. テーマを選んで「読みはじめる」
3. **辞書を引かずに**最後まで読む。分からない語は飛ばす
4. 「読み終えた」→ 読みごこちを3択で申告（これがレベル調整に使われます）
5. 語数・読む速さ・累計が記録される

しんどいと感じたら、途中で「これはやめて、別の文章にする」を押してください。ペナルティはありません。やめる自由を確保しておくことが、多読を続けるコツです。

## 記録の書き出し

設定画面の「記録を書き出す (JSON)」で全履歴をダウンロードできます。日付・テーマ・語数・wpm・レベル・読みごこち申告が入っているので、スプレッドシートで累積グラフを作るなどの用途に使えます。

## 注意点

- ブラウザから直接 Anthropic API を呼ぶ作りのため、**API キーが通信内容に含まれます**。自分専用の端末でのみ使い、URLを他人と共有したり公共のPCで使ったりしないでください。
- API 利用には従量課金が発生します（1セッション数円程度が目安）。
- 生成される文章は毎回AIが新規に書き下ろすオリジナルです（実在の書籍・記事からの引用ではありません）。

## カスタマイズ

- レベルと語彙帯 → `app.js` の `LEVELS`
- 節目の語数 → `app.js` の `MILESTONES`
- テーマ一覧 → `index.html` の `topicSelect` と `app.js` の `TOPIC_POOL`
- 生成の指示内容 → `app.js` の `buildSystemPrompt()`
- 配色 → `styles.css` 冒頭の `:root`
