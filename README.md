# Reading Lamp Premium 個人用版 v2.11.19

英語多読アプリ「Reading Lamp Premium」の個人用版です。全3,000篇・415,357語と103個のリワードを利用できます。広告とAI英文生成機能はありません。

読書画面のカスタマイズ、読書分析、お気に入り、読書履歴のJSONバックアップ、オフライン読書、2026年9月23日〜10月8日の秋イベントに対応しています。

2026年10月6日、制作マニュアルに沿って作成・校閲した430篇（s2571〜s3000）を追加しました。各レベル・ジャンルに43篇ずつ配分し、語数、難易度、本文の重複、校閲記録との整合性を検査しています。既存の2,570篇、文章ID、保存キー、リワードの定義は変更していません。

更新中に通信が切れて旧版で起動した場合も、再接続後に更新版の保存が完了すると、再読み込みせずに追加文章を選べます。読書中の文章、履歴、お気に入り、設定は保持されます。

本文とバージョン情報の整合性、Service Workerの更新、Chromiumでの主要な操作を検証しています。ブラウザー検証には、追加文章の読書、お気に入り、読了記録、旧版バックアップの復元、オフライン読書、通信切断後の更新再開、103個のリワードが含まれます。

本文・版情報の整合性検査とService Workerの更新検査は `npm test`、ブラウザー検証は `npm run test:ui` で実行できます。Node.js 20以上と、`npm ci` および `npx playwright install chromium` が必要です。旧版からの更新検証に使うコミット `f443f92886f58e4fe2520baf0f7c4092304fff31` が浅いクローンに含まれない場合は、`git fetch origin f443f92886f58e4fe2520baf0f7c4092304fff31` で取得してください。

Android・iPhoneの実機検証、対象年齢の最終確認、Google Playの実決済検証は未実施です。

GitHub Pagesはリポジトリのルートから配信します。`stories.json` の全文が公開されるため、Google Playの課金版では有料本文を分離した構成を使用してください。
