# Reading Lamp — 英語多読アプリ

Extensive Reading (ER, 多読) の研究知見にもとづいて設計した PWA です。スマホのホーム画面に追加してネイティブアプリのように使えます。

## 設計の土台となっている多読の原則

このアプリの仕様は、以下の原則から逆算して作られています。機能を足したり変えたりするときは、この表と照らして判断してください。

| 原則 | アプリでの実装 |
|---|---|
| テキストは「やさしい」こと（既知語95〜98%、未知語は100語あたり1〜2語） | レベル1〜10のグレーデッド・リーダー準拠の語彙帯。生成プロンプトの最優先ルールとして明記 |
| 「少し易しすぎる」レベルから始め、退屈になってから上げる | 読後に3択で読みごこちを申告。難のときは即座に1段階下げ、同じレベルで「易」が3回連続したときだけ1段階上げる |
| 量が学習効果の中核（年間100万語が目標） | ホーム画面の主役は累計語数カウンタ。1万→100万語の節目バーを表示 |
| 読書速度・流暢さの向上が主要な成果指標 | 本文が実際に表示されていた時間だけを計測し、直近5回の有効な語数÷読書時間から語/分 (wpm) を表示 |
| 辞書使用は最小限。分からない語は飛ばす | 本文画面に辞書機能を一切置かない。ホームで毎回リマインド |
| 読書そのものが報酬。読後テストは行わない | 振り返り・語彙リスト・理解度クイズの機能は持たない |
| 読み手が読みたいものを自分で選ぶ | テーマ選択（10テーマ＋自由入力＋おまかせ） |
| 退屈な本はやめてよい（脱落の自由） | 本文画面に「これはやめて、別の文章にする」。語数は加算せず、記録には残る |
| 毎日同じ時間に少量でも継続 | 連続日数と1日の目標語数（既定1,500語）を表示 |

## レベルの目安

| Lv | 語彙帯 | 目安 |
|---|---|---|
| 1 | 300語 | ごく易しい。短く単純な文 |
| 2 | 600語 | 日常的な話題 |
| 3 | 800語 | 単純な物語が読める |
| 4 | 1,000語 | 時制が自在に |
| 5 | 1,400語 | 描写や説明が増える（初期値） |
| 6 | 1,800語 | 抽象的な話題も少し |
| 7 | 2,500語 | 複文や比喩が自然に |
| 8 | 3,000語 | 論説的な文章も |
| 9 | 4,000語 | 原書に近い語彙 |
| 10 | 無制限 | 簡略化なし。一般書・報道と同水準 |

初期値はレベル5です。TOEIC 750 / B2 相当の力があっても、多読では実力より低いところから始めるのが正解です。「退屈なほど楽」と感じるまで上げないでください。上げるのを急ぐと、多読ではなく精読になってしまいます。

### WPM計測とレベル調整

- WPMは本文画面が表示され、ページが前面にある時間だけで計算します。別タブへの移動、画面ロック、アプリのバックグラウンド滞在は読書時間に含めません。
- 10秒未満の読了、または10未満・600超のWPMは誤操作や計測異常の可能性が高いため、WPM統計から除外します。ホームのWPMは、直近5回の有効記録について合計語数を合計読書時間で割って算出するため、短い文章だけが平均を大きく動かしません。語数と読了記録は通常どおり残ります。
- 「難しかった」は次の文章から1レベル下げます。「ちょうどよかった」は現在レベルを維持します。
- 「やさしすぎた」は同じレベルで3回連続した場合だけ1レベル上げます。途中でやめる、「ちょうどよかった」を選ぶ、または設定からレベルを手動変更すると連続回数はリセットされます。

## オフラインの文章バンク（APIキー不要）

初回からオフライン文章バンクが標準で有効です。Anthropic APIを一切呼ばずに、あらかじめ用意した文章から出題します。通信費・API利用料がかからず、一度アプリ一式を読み込んだ後は完全オフラインでも使えます。

- 現在収録：**1,610篇・305,511語**（ID `s001`〜`s1610`、レベル1〜10 × 全10テーマ）
- 全10テーマ × 10レベルの**100組すべてに最低15篇**を配置しています。
- 追加した3テーマ：`Mystery and adventure`（170篇）、`Travel and culture`（170篇）、`People and biography`（170篇）
- 既存テーマは履歴との互換性を保つため内部名を維持し、画面上では `Fantasy`・`Classics / Retellings`・`Society / World`・`Science / Technology` と分かりやすく表示します。
- 文章バンクは文体・語彙・構文を全件監査済みです。優先確認102篇を起点に低レベルから本文を再編集し、Level 1〜10の構文確認もすべて解消しました。個人向けリリース版から合計937篇を更新しています。ID・レベル・テーマは維持し、事実と異なる仕組みを示していたタイトル1件だけを修正しています。
- 新規3テーマは各170篇。Level 1〜4は各テーマ20篇、Level 5〜10は各15篇を配置しています。
- `Famous books` は、十分古い古典作品の筋・人物・設定をもとに、多読用として新規に書き下ろしたリテリングです。原文や現代の翻訳文は転載していません。
- 全篇に教材管理用メタデータを付けています。アプリは `editorialStatus: "published"` の文章だけを出題し、下書き・確認中・公開終了の文章を文章バンクへ混ぜません。
- 選んだテーマとレベルの組み合わせの中で、一度読んだ文章は他のストックがなくなるまで再表示されません。読み尽くすと記録をリセットして次の周からまた出題します（直前に読んだ1篇だけは連続を避けます）
- レベル調整（読後の3択フィードバック）は文章バンクモードでも動作します

### 1,610篇の語彙レベル監査

全篇について、一般英語での語の使用頻度、極低頻度語、8文字以上の語、平均文長を監査しました。詳細は`VOCABULARY_AUDIT.md`、篇ごとの数値は`vocabulary_audit_1610.csv`に収録しています。さらに、数値上残る単一指標を全件編集判定し、`VOCABULARY_EDITORIAL_REVIEW.md`と`vocabulary_editorial_review_1610.csv`に判断理由を記録しました。

- 運用ガードレール内：1,292篇
- 構文のみ要確認：0篇
- 単一語彙指標の超過：318篇（全件編集判定済み）
- 優先確認（語彙指標を2種類以上超過）：0篇
- 編集未判定：0篇

単一指標の超過は不合格ではありません。318篇はいずれも、長語率・低頻度語率・極低頻度語率のうち一つだけが閾値を超えたものです。`children`や`together`のような長い日常語、動植物名、題材固有の科学語を全件確認し、中心概念を失う置換を避けて維持しました。未確認のまま残した篇はありません。

文章を追加する場合は、`stories.json`に本文情報と、`subtopic`・`contentType`・`editorialStatus`・`factChecked`・`reviewedAt`・`sourceWork`・`vocabularyVersion`を追加します。本文を変更した場合は`wordCount`も再計算してください。公開承認前は `editorialStatus` を `draft` または `reviewed` とし、出題可能にするときだけ `published` に変更します。詳しい定義は`METADATA_SCHEMA.md`にあります。

## 公開方法（おすすめ：GitHub Pages、無料）

1. GitHub に新しいリポジトリを作り、このフォルダの中身一式をアップロード
2. Settings → Pages で公開元を「main ブランチ / root」に設定
3. 発行された `https://アカウント名.github.io/リポジトリ名/` にスマホでアクセス
4. iPhone Safari なら共有 →「ホーム画面に追加」、Android Chrome なら右上メニュー →「アプリをインストール」

Netlify・Vercel・Cloudflare Pages へのドラッグ＆ドロップでも構いません。

### 公開前に設定する項目

`privacy.html`と`terms.html`は個人向け初回公開に合わせた内容ですが、公開前に配布ページへ**運営者名または屋号**と**実際に連絡を受け取れる問い合わせ先**を掲載してください。将来、課金・会員登録・クラウド同期・広告・アクセス解析を追加するときは、規約とプライバシーポリシーも更新が必要です。

## 使い方

1. 初回の案内で開始レベル、興味のあるジャンル、1日の目標を選ぶ
2. テーマを選んで「文章バンクから読みはじめる」
3. 必要に応じて右上の歯車からレベルと1日の目標語数を調整
4. **辞書を引かずに**最後まで読む。分からない語は飛ばす
5. 「読み終えた」→ 読みごこちを3択で申告（これがレベル調整に使われます）
6. 語数・読む速さ・累計が記録される

## 個人向けリリース機能

- 初回オンボーディング：多読の説明、開始レベル、ジャンル、1日の目標を3画面で設定。設定画面から再表示できます。
- 読みかけの復元：読書中の文章、実際に読んだ時間、スクロール位置を端末へ自動保存します。再読み込み、PWA更新、ブラウザ終了の後もホームから続きへ戻れます。「読み終えた」の後に閉じた場合は、読みごこちの入力画面から再開します。
- お気に入り：文章バンクの各篇を保存・解除し、ホームのお気に入り一覧から再読できます。
- 文章の問題報告：問題の種類と任意の補足を選び、文章ID・レベルを含む報告を端末の共有機能またはJSONファイルで渡せます。自動送信はしません。
- 規約とプライバシー：ホームと設定から`terms.html`・`privacy.html`を確認できます。

新しいアプリ版が準備できると、画面下部に更新通知が表示されます。「更新する」を押すと新しいキャッシュへ切り替えて自動的に再読み込みします。「あとで」を選んだ場合は、次回起動時またはアプリへ戻ったときに再確認します。

ホームの「読書履歴の分析」を開くと、読了篇数、直近7日の語数、1篇平均語数、途中終了率、WPMの変化、テーマ別・レベル別の傾向を確認できます。途中終了の理由も集計されます。

読みかけの文章は開始時、読書中は15秒ごと、スクロール後、アプリがバックグラウンドへ移るときに保存されます。再開までの閉じていた時間はWPMへ加算しません。「今回は再開しない」を選んだ場合は読みかけデータを削除し、その文章を未読候補へ戻します。保存内容はこの端末内だけにあり、端末間では同期されません。

設定の「読書画面の表示」では、次の項目をプレビューしながら変更できます。設定はこの端末に保存され、次回起動時にも反映されます。

- 文字サイズ：16〜26px
- 行間：1.5〜2.2
- 書体：セリフ体／ゴシック体
- 本文背景：ナイト／セピア／高コントラスト

AI生成を使う場合は、設定で「オフライン文章バンク」をオフにし、Anthropic APIキーを入力します。一度保存すると同じ端末のブラウザに記憶され、ページの再読み込みやアプリの再起動後も自動で使われます。「AI生成する文章の目安語数」はこのモードでだけ表示・使用されます。オフライン文章バンクでは、各篇に保存された適切な長さをそのまま使います。また、自由テーマの指定はAI生成モード専用です。

しんどいと感じたら、途中で「これはやめて、別の文章にする」を押してください。理由を「難しすぎた」「興味を持てなかった」「長すぎた・時間不足」「用事などで中断」「その他」から選べます。「難しすぎた」のときだけ次から1レベル下げ、ほかの理由ではレベルを変えません。語数は加算されず、途中でやめたこと自体にペナルティはありません。

## 記録とお気に入りの書き出し

設定画面の「記録とお気に入りを書き出す (JSON)」でバックアップをダウンロードできます。履歴には日付・テーマ・文章ID・語数・wpm・有効読書秒数（`activeSeconds`）・計測有効性（`wpmValid`）・読書前後のレベル・読みごこち申告・途中終了理由が入り、お気に入り文章IDも一緒に保存されます。

「記録とお気に入りを復元する (JSON)」では、書き出したファイルを読み込み、現在のデータを残したまま重複を除いて追加します。以前の履歴だけのJSONにも対応します。日付、語数、WPM、レベル、文章IDなどを検証してから保存し、不正なファイルでは現在のデータを変更しません。端末内には新しい順で最大2,000件の履歴と、最大500篇のお気に入りを保持します。

端末内の履歴が途中で欠けた、配列でない、または一部に不正な記録が混ざった場合も、アプリ全体を停止させず、読み取れる記録だけで起動します。修復前の履歴は端末内に一時退避され、設定画面の「保存データを修復しました」からJSONとして保存できます。退避データにAPIキーや読みかけ本文は含まれません。内容を確認した後は同じ画面から削除できます。「記録をすべて消去する」を選んだ場合は退避データも削除します。

## アクセシビリティ

- 設定、初回案内、途中終了理由、問題報告画面に、読み上げ用のダイアログ名・説明・モーダル属性を設定
- 開いたときにダイアログ内へフォーカスを移し、Tabキーをダイアログ内で循環
- Escapeキー、背景クリック、閉じるボタンで終了し、元の操作位置へフォーカスを戻す
- 背景を操作対象外にし、モーダル表示中の本文計測を一時停止
- スライダーの現在値を読み上げ用テキストとして提供
- 復元結果とエラーをライブ領域で通知
- 高コントラスト本文テーマと、読み手に合わせた文字サイズ・行間・書体を提供

## PWAアイコン

通常アイコンとは別に、Androidの円形・角丸・スクワークルなどのマスクで使われる専用maskableアイコンを192pxと512pxで収録しています。ランプと本を中央の安全領域へ収め、外周は透過のない濃紺背景で構成しています。`manifest.json`では通常用を`purpose: any`、専用版を`purpose: maskable`として分けています。

## 注意点

- 標準のオフライン文章バンクではAPIキーを使用しません。
- AI生成モードのキーは、この端末の`localStorage`に保存します。設定画面の「この端末からAPIキーを消去」でいつでも削除できます。共有端末や第三者が操作できる端末には保存しないでください。
- `localStorage`は暗号化された秘密保管庫ではありません。同じ配信元で動くJavaScriptや、端末・ブラウザの利用者から読み取られる可能性があります。信頼できる場所に配置したアプリと個人所有の端末でのみ使用してください。
- AI生成時はブラウザからAnthropic APIへ直接キーを送ります。通信先はCSPでAnthropicと同一オリジンのみに制限し、外部フォントなどの第三者通信も削除しています。
- 多人数へ公開する場合は、利用者にAPIキーを入力させず、認証・利用上限を備えたサーバー側プロキシへ移行するのが最も安全です。本版はGitHub Pagesなどの静的公開を維持するため、端末内保存方式を採用しています。
- API 利用には従量課金が発生します（1セッション数円程度が目安）。
- 生成される文章は毎回AIが新規に書き下ろすオリジナルです（実在の書籍・記事からの引用ではありません）。
